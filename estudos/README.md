# Material de estudo

Guia interativo da estatística e das métricas usadas no Bairrômetro, com o porquê de cada escolha e as referências científicas.

**Separado do sistema de busca:** nada nesta pasta é usado pelo Bairrômetro em funcionamento. Os bairros e números dos exemplos são fictícios.

## Como abrir

Na raiz do projeto:

```bash
python -m http.server 8765 --bind 127.0.0.1 --directory estudos
```

Depois abra http://localhost:8765 no navegador. Para parar, `Ctrl+C` no terminal.

O arquivo também abre direto no navegador (duplo clique em `index.html`), sem servidor.
